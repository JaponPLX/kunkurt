✉️ Configuración para enviar correos reales a Gmail

Para que los correos lleguen a tu bandeja real de Gmail (en lugar de simularse), Google requiere una Contraseña de Aplicación de 16 letras (App Password), ya que no permite contraseñas personales directas por motivos de seguridad.

Pasos rápidos para obtener tu contraseña de Gmail:
1. Entra a tu cuenta Google: myaccount.google.com/security
2. Asegúrate de tener activa la Verificación en 2 pasos.
3. Busca Contraseñas de aplicaciones (o visita myaccount.google.com/apppasswords).
4. Crea una contraseña llamada "Kunkurt" y copia el código generado de 16 caracteres.
